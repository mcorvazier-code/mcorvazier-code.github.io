# Mission Rétro-automatique · V3

Version de travail avec « l'ancienne salle d'études » : à la fin de chaque mission, l'élève reçoit les exercices
de la banque correspondant aux notions où il a fait des erreurs (ou des exercices d'approfondissement s'il n'en a fait aucune),
saisit ses résultats et le jeu les vérifie. Ces exercices ne comptent pas dans le score.

La V2 (dossier `retro-automatique/`) reste le jeu en ligne. La V3 utilise les mêmes ressources
(`<base href="../retro-automatique/">`) mais ses propres sauvegardes.
